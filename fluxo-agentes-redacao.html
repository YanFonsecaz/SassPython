Fluxo de Agentes

Sistema multiagente para criação de conteúdo SEO com banco de dados vetorial e revisão humana

Descrição Completa do Fluxo

01
ENTRADA DO USUÁRIO

Tela de Cadastro de Cliente e Configuração da Redação

O usuário acessa uma tela de formulário onde insere todas as informações necessárias para a geração do conteúdo. Os campos obrigatórios são: configuração (contexto geral do projeto), cliente (nome da empresa ou marca), meu cliente (identificação do cliente final) e tópico (tema central do conteúdo, ex.: "Guia de SEO local para clínicas").

Além disso, o usuário preenche: palavra-chave principal, palavras-chave secundárias (separadas por vírgula), tipo de conteúdo (blog post, artigo, etc.), meta de palavras, objetivo, artigo introdutório e perguntas de clientes, e instruções adicionais para a IA.

02
CONFIGURAÇÃO DE PERSONAS

Definição de Personas por Cliente

Dentro do cadastro de cliente, o usuário deve definir as personas que o negócio deseja alcançar. Para cada persona é necessário configurar: tom de voz, nível técnico de comunicação, estilo de escrita (ex.: direto, didático ou persuasivo), além de palavras proibidas e palavras que devem ser utilizadas. O objetivo de persona também é relevante pois influencia diretamente na forma como o conteúdo será gerado.

Além das personas individuais, existe uma configuração global de tom de voz que serve de base para todas as personas, garantindo consistência na comunicação. É recomendado incluir exemplos de textos que representem bem o estilo desejado, ajudando a orientar melhor a geração de conteúdo pela IA.

Nota: A persona influencia diretamente o Agente Redator, que ajustará tom, vocabulário e estilo de escrita com base nessas configurações.
03
AGENTE 1 — PESQUISADOR DE TENDÊNCIAS

Pesquisa de Tópico e Tendências via Google e SERPs

O primeiro agente é acionado com a palavra-chave principal fornecida pelo usuário. Sua responsabilidade é pesquisar o tópico na web, no Google Trends e nas SERPs, identificando os conteúdos mais relevantes, bem ranqueados e em alta para aquele tema.

A pesquisa deve ser feita com uma ferramenta disponível apenas para esse agente específico. O agente deve ser baseado em 3 a 10 conteúdos encontrados no banco de dados vetorial. O banco de dados vetorial deve ter todos os conteúdos já cadastrados, e os metadados devem ser compatíveis com o seguinte schema:

tipo: "blog" | produto | categoria | "notícias" | "instagram" | "tópico" | ... intenção: "informacional" | comercial | ... palavras_chave: ["blog protein", "massa muscular", "treino"] atividades: ["whey", "proteína", "treino"]

O agente também deve fazer cache para evitar chamadas repetidas para o mesmo tópico, otimizando o uso da API e reduzindo custos.

04
AGENTE 2 — ANALISADOR DE CONTEÚDOS

Análise de Conteúdos no Banco de Dados Vetorial

O segundo agente é responsável por analisar os conteúdos guardados no banco de dados vetorial e filtrar os 3 melhores conteúdos de acordo com o que o usuário quer criar. Essa análise considera a compatibilidade semântica com o tópico, as palavras-chave e a intenção de busca declarada.

Após a análise, o agente cria um brief ou esboço com os dados encontrados, definindo o outline e a estrutura do conteúdo que será escrito. Esse brief serve como guia para o Agente Redator.

A seleção dos conteúdos usa a seguinte fórmula de pontuação aplicada ao banco vetorial:

score = ( Vec{{similaridade_coseno}} + Vec{{relevância_contextual}} + Vec{{atualização_por_região}}{{Top 4 Busca}} + Vec{{penalização_por_repetição}}{{Top 4 Busca}} ) → Ordenar por score → Filtrar com threshold (corte mínimo) → Selecionar Top 4/5 para inserção
05
AGENTE 3 — CRIADOR DE BRIEF

Criação do Brief com Outline e Estrutura

Com base nos conteúdos selecionados pelo agente anterior, este agente é responsável por criar um brief completo que define o outline (estrutura de tópicos) e a organização do conteúdo final. O brief leva em conta as informações importantes encontradas nas SERPs, a intenção do usuário e as melhores práticas de SEO.

06
AGENTE 4 — REDATOR

Redação do Conteúdo com Tom de Voz da Persona

O Agente Redator recebe o brief criado pelo agente anterior e escreve o conteúdo completo. Ele deve respeitar rigorosamente o tom de voz da persona configurada pelo usuário: nível técnico de comunicação, estilo de escrita (direto, didático, persuasivo), palavras proibidas, palavras recomendadas e o objetivo da persona.

O agente deve seguir a estrutura e outline definidos no brief, aplicando as melhores práticas de SEO on-page ao longo do texto gerado.

07
AGENTE 5 — REVISOR

Revisão do Conteúdo Gerado

Após a redação, o Agente Revisor analisa o conteúdo produzido e verifica aderência ao brief, coerência textual, uso correto das palavras-chave, tom de voz e estrutura. O conteúdo é então apresentado ao usuário para aprovação.

✓ Aprovado

O conteúdo é aprovado pelo agente revisor e apresentado ao usuário para validação final.

✗ Reprovado

O conteúdo é reprovado e retorna ao Agente Redator com feedback detalhado. O usuário pode reprovar até 3 vezes; após isso o feedback é enviado diretamente ao usuário.

08
REVISÃO HUMANA

Validação pelo Usuário

O conteúdo aprovado pelo revisor é apresentado ao usuário, que tem a opção de aprovar ou reprovar. Caso reprove, o usuário deve enviar um feedback indicando o que deve ser corrigido. Esse feedback é passado diretamente ao Agente Redator para que o conteúdo seja reescrito de acordo com as instruções.

✓ Usuário Aprova

Fluxo segue para o próximo agente (geração de imagem).

✗ Usuário Reprova

Texto e feedback são reenviados ao Agente Redator para revisão e reescrita.

09
BANCO DE DADOS VETORIAL

Armazenamento do Conteúdo Aprovado no Histórico

Após a aprovação do usuário, o conteúdo é salvo no banco de dados vetorial, alimentando o histórico de conteúdos aprovados por aquele cliente. Esse histórico é usado em futuras gerações para que o sistema aprenda e respeite o estilo, padrões e preferências já validados pelo usuário.

10
AGENTE 6 — GERADOR DE IMAGEM

Geração de Imagem para o Conteúdo (Blog/Post)

Com o conteúdo aprovado, um agente responsável por gerar o prompt de imagem é acionado. Esse agente cria um prompt baseado no conteúdo para uso em ferramentas de geração de imagem via IA (ex.: DALL-E, Midjourney, Stable Diffusion).

O conteúdo final, junto com a imagem gerada, é então entregue ao usuário pronto para publicação no blog ou outra plataforma.
